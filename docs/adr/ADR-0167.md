### ADR-0167: Visibilidad Global de Configuración — Modo Simple y Avanzado

**¿Qué decidimos?**

La aplicación de escritorio ofrece un selector global de visibilidad de configuración, accesible desde un menú en cualquier pantalla. El modo inicial es **simple**; el usuario puede cambiarlo a **avanzado**. La preferencia se conserva localmente para el usuario de la instancia.

El modo simple muestra los controles esenciales y los necesarios para operar de forma segura. El avanzado muestra además los controles que cada feature o módulo clasifique como avanzados. Ambos modos usan la misma configuración efectiva y los mismos procesos.

**¿Por qué lo decidimos?**

Una persona puede comenzar con una superficie comprensible y revelar los ajustes detallados cuando los necesite. Mantener una sola configuración evita que alternar entre niveles de detalle cree valores divergentes o borre trabajo.

**¿Qué restricciones tiene?**

- Cada control configurable declara si es esencial o avanzado. No hay selectores de modo independientes por feature, módulo o inspector.
- Cambiar el modo solo modifica la visibilidad: no reinicia ni sustituye parámetros, conexiones, cambios pendientes, procesos o resultados.
- Guardar desde cualquier modo conserva los valores que ese modo no muestra. No existen copias separadas de la configuración para simple y avanzado.
- En modo simple, una feature o módulo con ajustes avanzados distintos de sus valores predeterminados muestra que tiene personalización avanzada activa.
- El modo avanzado no amplía permisos, licencias ni capacidades y no omite validaciones o controles de seguridad.
- Conectar nodos, arrastrar features y usar plantillas recomendadas está disponible en ambos modos, sujeto a las mismas autorizaciones.
- La densidad ajustable de cada widget del Dashboard es una preferencia de presentación independiente del selector global; no cambia esta configuración efectiva.

**¿Cómo se vería en el sistema?**

El usuario abre el menú global y activa el modo avanzado. Los inspectores y configuradores muestran sus controles adicionales sin cambiar de pantalla. Después modifica un valor avanzado y regresa al modo simple: el valor sigue vigente y la superficie indica que existe una personalización avanzada. Al reabrir la interfaz se recupera el último modo elegido.

**¿Qué cuesta?**

Cada superficie configurable debe clasificar sus controles, conservar los valores ocultos al guardar y representar las personalizaciones avanzadas. La aplicación debe mantener coherente el selector entre superficies y restaurar la preferencia local.
