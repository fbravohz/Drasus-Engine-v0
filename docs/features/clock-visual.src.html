Clock entrega tiempo real o reproducible

El Core consulta un solo puerto. El proceso de ejecución inyecta un reloj de sistema o uno determinista; ambos devuelven Unix en nanosegundos como i64.

Contrato

Un puerto conecta a todos los consumidores con el reloj elegido

El Core no consulta el reloj del sistema directamente. SystemClock convierte la hora de pared a nanosegundos y fuerza lecturas crecientes; DeterministicClock mantiene el valor hasta un avance explícito.

Auditoría

Tres eventos llegan a Audit Log; las lecturas frecuentes quedan fuera

Los payloads viven en details_json: ntp_sync_offset_ns, from/to, y real_virtual_delta_ns junto con virtual_process_id.

El código define y exporta los tres emisores. La búsqueda de llamadas en archivos Rust solo encontró definiciones, pruebas y reexportaciones; no localizó una integración productiva que dispare esos hitos.
