# Legacy context archive

This directory preserves the former `Drasus-Context` repository as reference
material. `drasus-context/` is the clean versioned source. `drasus-context-working-copy/`
preserves the recovered local tree. Neither is a discovered skills directory,
is loaded by the active context provider, or is a source of runtime instructions.

Promote material from here only when a current Codex workflow needs it. Move
the promoted material into an active skill or focused knowledge reference,
remove platform-specific assumptions, define its owner, and add validation.
