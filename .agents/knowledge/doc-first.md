# Buscar antes de decidir

## DOC-FIRST-1 — Fuente de verdad

Antes de proponer una regla, fórmula, contrato o cambio de alcance, consulta
`docs/README.md`, busca con `rg` en los ADRs, SADs, features y código pertinente,
y lee los resultados relevantes. Una memoria o un resumen no sustituyen el canon.

Cita la fuente que sostiene o contradice la propuesta. Si no hay cobertura,
indica carpetas y patrones buscados: la ausencia también necesita evidencia.
Una decisión existente se aplica; un vacío real se explicita y se resuelve
dentro de la autorización del usuario, con revisión de dominio cuando corresponda.

Los documentos más específicos y vigentes gobiernan; conserva banners y enlaces
de supersesión para resolver una contradicción, sin borrar el historial.
